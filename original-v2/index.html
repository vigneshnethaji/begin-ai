01. Create your starter repository

These commands do not call any paid AI service.

Terminal · .NET SDK
dotnet --info
mkdir dotnet-ai-learning
cd dotnet-ai-learning
dotnet new sln -n DotNetAiLearning
dotnet new console -n Warmup -o src/Warmup
dotnet sln add src/Warmup/Warmup.csproj
dotnet new xunit -n Warmup.Tests -o tests/Warmup.Tests
dotnet sln add tests/Warmup.Tests/Warmup.Tests.csproj
dotnet run --project src/Warmup
# ML.NET is introduced later; a paid model API is introduced much later

When you reach Module 25, choose an API provider. Store credentials using environment variables or .NET user secrets. Do not paste an API key into the browser or this offline learning site.

02. Add tools only as you need them

Keep the learning stack small at the beginning.

Foundations firstC# • .NET SDK • xUnit • ML.NET; no AI API needed initially
Search & RAGfloat[] + LINQ first, then pgvector/Qdrant, PDF parser, Azure AI Search
Agents & MCPTool calling first, then Microsoft.Extensions.AI • Agent Framework • MCP C# SDK
ProductionEntra ID • Blob Storage • Key Vault • OpenTelemetry • App Insights
Optional depthOllama • ONNX Runtime for C# • Azure ML • advanced research later
